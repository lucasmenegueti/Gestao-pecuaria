Gestão Mecânica · Proposta de Redesign

Redesign do app gestao-mecanica alinhado ao sistema de design NSA. Mantém toda a lógica atual (Menu, OS abertas, Nova OS, Dashboard, Máquinas) e a estrutura de dados — apenas troca o vocabulário visual do azul Next.js padrão para o verde-cedro + creme da marca, ajusta tipografia, densidade e hierarquia.

lucasmenegueti/gestao-mecanica@main · mobile-first 390px · 8 telas principais

Princípios aplicados neste redesign

  • Cor primária trocada de #185FA5 para #172514 (nsa-green) com acento creme em elementos de destaque. Botões selecionados passam a usar bg-bg2 + borda verde em vez de bg azul claro.
  • Header com fundo verde profundo em telas-chave (Menu, OS, Nova OS) no lugar do header branco com borda. Dá identidade imediata sem fugir do padrão mobile-first.
  • Tipografia Inter substitui a stack system-ui. Títulos grandes em Lora (serif) nos headers de contexto — reflete a marca.
  • Tabular numerals em toda contagem (dias parados, OS #, dashboard). Já funciona com Inter sem configuração extra.
  • Ícones Lucide 1.75 stroke, 18–22px. O app atual é praticamente icon-less; ícones bem usados aumentam scan-ability nas listas.
  • Status pills semânticas com dot de 5px (padrão do sistema): ok · warn · danger · info · neutral. Mapeamento: Urgente→danger, Normal→info, Baixa→neutral, Concluído→ok, Aberta→warn.
  • Raio de cartões mobile → 14px (em vez de 8px) para sensação mais macia, alinhado com iOS / padrão mobile moderno.
  • FAB "Nova OS" flutuante na tela de OS abertas em vez de item 3 no grid de menu. Ação mais frequente deve ser acessível de qualquer lugar.
